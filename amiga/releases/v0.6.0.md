# NHL94AGA 0.6.0 (preview): the game on screen, with sound and controllers

> **Credits:** built on [NHL94Genesis](https://github.com/abdulahmad/NHL94Genesis) by abdulahmad, with chaos,
> StaticEck, McMarkis (Mhopkinsinc) and Drezz, and special thanks to smozoma and kingraph. The C, its runtime
> (pulseman) and its verification tools are by 1nput ([ninety-four](https://github.com/1nputs/ninety-four), MIT).

The first version of the native Amiga 1200 (AGA) port of NHL '94 you can play: the game's own logic,
its picture on the A1200's display, its sound on Paula, and the Amiga's own controllers.

**Asset:** `nhl94-aga-v0.6.0.adf`, SHA-256 `74cc1433ae4ea090351d61caf9cbb287b2538ae42f36f207593b66bf2a36fce8` (built from commit 7f35fcf).

## What you need

* An Amiga with AGA and a 68020 or better; the target is an **A1200 with Fast RAM** (D-14).
* Kickstart 3.0 (39.106) or 3.1 (40.068).
* **Your own dump of the 1 MB US/Europe NHL '94 cartridge.** The disk holds none of the cartridge's art,
  sound or data: the instruments, the picture and everything else are made from your cartridge on your
  Amiga. Put it at `NHL94ROM:nhl94.bin`, `RAM:nhl94.bin` or beside the program, or on two floppies
  (`NHL94ROMA:nhl94.rom.1` and `NHL94ROMB:nhl94.rom.2`, the halves). The program checks its CRC32.

## Playing

Boot the disk. Keyboard: cursor keys, Z = A, X = B, C (or Space, Return) = C, P = Start, Esc quits.
Joystick in port 2: fire 1 = B, fire 2 = A. CD32 pad: red B, blue C, yellow and green A, play Start.

## Status (from a cycle-exact emulated A1200; real hardware confirmation comes before 1.0.0)

* Every picture is drawn exactly as the reference (checked on every pass of the test scripts).
* Menus run at full speed. **Matches run at about half speed** in this version; making them full speed is
  the next work.
* The sound is a first version (mono, fixed instrument timbres).

The full log of the work is `amiga/STATUS.md`, the changes `amiga/CHANGELOG.md`, the test sheet
`amiga/tests/v0.6.0.md`.

## About the cartridge data in the program

The game's compiled C holds some short tables and strings from the cartridge, all from source committed in
this repository, as the host releases of this project do (allowed by the owner, D-12). The disk check
(A-LEGAL) passes: no other byte of the ROM is on the disk.
