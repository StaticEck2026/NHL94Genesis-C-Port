# NHL94AGA 0.5.1 (preview): faster logic, and the display requests checked

> **Credits:** built on [NHL94Genesis](https://github.com/abdulahmad/NHL94Genesis) by abdulahmad, with chaos,
> StaticEck, McMarkis (Mhopkinsinc) and Drezz, and special thanks to smozoma and kingraph. The C, its runtime
> (pulseman) and its verification tools are by 1nput ([ninety-four](https://github.com/1nputs/ninety-four), MIT).

A preview of the native Amiga 1200 (AGA) port of NHL '94. **There is no picture or sound yet.** This disk
checks that the game's own C, compiled for the 68020, plays exactly as the reference does on your Amiga,
measures how long each pass of game logic takes, and now also checks every display request the game makes.

**Asset:** `nhl94-aga-v0.5.1.adf`, SHA-256 `7130a61ca113f2d98a0616664e134e0f8bb3683fdadab5bc4671b21460d31d23` (built from commit 2af7911).

## What is new since 0.5.0

* The game's logic is two to four times faster, with the same results on every pass. Emulated A1200 with
  8 MB Fast RAM: a pass takes 1.0 to 3.9 ms on average of the Genesis's 16.7 ms frame (was 4 to 10 ms),
  and the longest pass, a rink being loaded, takes 0.3 s (was 1.9 s; the cartridge itself takes 0.9 s).
* `NHL94VFY <script> INTENT` hashes every display request of every pass (tiles, cells, palette, scroll)
  for comparison with the reference. This is the interface the display will be built behind.
* `NHL94VFY <script> PROFILE FIRST LAST` profiles a window of passes.

## What you need

* An Amiga with AGA and a 68020 or better. The target is an **A1200 with Fast RAM** (D-14). A stock 2 MB
  A1200 runs the checks too, more slowly.
* Kickstart 3.0 (39.106) or 3.1 (40.068).
* **Your own dump of the 1 MB US/Europe NHL '94 cartridge.** The disk holds none of the cartridge's art,
  sound or data. Put it at `NHL94ROM:nhl94.bin`, `RAM:nhl94.bin` or beside the program, or on two floppies
  (`NHL94ROMA:nhl94.rom.1` and `NHL94ROMB:nhl94.rom.2`, the halves). The program checks its CRC32.

## Status

Provisional results from a cycle-exact emulated A1200 (decision D-13); real hardware confirmation comes
before 1.0.0:

* Every frame of all seven scripts (69,293 frames) matches the reference exactly, in the game's RAM and
  in the display requests.
* With Fast RAM, no pass is later than the cartridge's own (compared by rank). A few passes still run
  over a frame with a picture on screen (the in-game roster screen as its list scrolls, 15 to 17 ms).
* On a stock 2 MB A1200 the logic alone averages 9 ms a pass and about one pass in seven is over a frame.

The full log of the work is `amiga/STATUS.md`, the changes are in `amiga/CHANGELOG.md`, and the test
sheet is `amiga/tests/v0.5.1.md`.

## About the cartridge data in the program

The game's compiled C holds some short tables and strings from the cartridge (windows of 32 bytes), all
from source committed in this repository, as the host releases of this project do. The owner allowed that
on 2026-11-20 (D-12). The disk check (A-LEGAL) passes: no other byte of the ROM is on the disk.
