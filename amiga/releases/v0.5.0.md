# NHL94AGA 0.5.0 (preview): the game's logic on the Amiga 1200

> **Credits:** built on [NHL94Genesis](https://github.com/abdulahmad/NHL94Genesis) by abdulahmad, with chaos,
> StaticEck, McMarkis (Mhopkinsinc) and Drezz, and special thanks to smozoma and kingraph. The C, its runtime
> (pulseman) and its verification tools are by 1nput ([ninety-four](https://github.com/1nputs/ninety-four), MIT).

A preview of the native Amiga 1200 (AGA) port of NHL '94. **There is no picture or sound yet.** This disk
checks that the game's own C, compiled for the 68020, plays exactly as the reference does on your Amiga,
and measures how long each frame of game logic takes.

**Asset:** `nhl94-aga-v0.5.0.adf`, SHA-256 `1c402ddfb7ae0434378e691f42deda9883b6ccf0c32e7ba69cf35db2bbac16fa`
(built from commit e709f65, tag `amiga-v0.5.0`).

## What is on the disk

* `NHL94VFY`: plays the repository's seven input scripts through the game's logic, times every frame with
  the E clock, and writes a hash of the game's RAM for every frame (`NAME.h32`). `amiga/tools/h32compare.py`
  checks those files against the reference on a PC.
* `NHL94AGA`: the boot test. It checks for Kickstart 3.0+, a 68020 and AGA, switches the chipset to AGA
  (as SetPatch does), takes the machine over the system-legal way, and shows a 24-bit copper screen.
  `NHL94AGA 20` gives the machine back by itself after 20 seconds.
* The input scripts, `ReadMe`, `Credits.txt` and `Changelog.txt`.

## What you need

* An Amiga with AGA and a 68020 or better. The target is an **A1200 with Fast RAM** (D-14). A stock 2 MB
  A1200 runs the checks too, more slowly.
* Kickstart 3.0 (39.106) or 3.1 (40.068).
* **Your own dump of the 1 MB US/Europe NHL '94 cartridge.** The disk holds none of the cartridge's art,
  sound or data. Put it at `NHL94ROM:nhl94.bin`, `RAM:nhl94.bin` or beside the program, or on two floppies
  (`NHL94ROMA:nhl94.rom.1` and `NHL94ROMB:nhl94.rom.2`, the halves). The program checks its CRC32.

## Status

Provisional results from a cycle-exact emulated A1200 (decision D-13); real hardware confirmation comes
before 1.0.0:

* Every frame of all seven scripts (69,293 frames) matches the reference exactly.
* On an A1200 with 8 MB Fast RAM, the game's logic takes 4 to 10 ms a frame on average, against the
  Genesis's 16.7 ms. Between 1% and 10% of frames still take longer than one frame, and work on those
  comes next.
* On a stock 2 MB A1200, the logic alone takes 122% of a frame (102% with the faster RAM accessors).

The full log of the work is `amiga/STATUS.md`, and the changes are in `amiga/CHANGELOG.md`.

## About the cartridge data in the program

The game's compiled C holds some short tables and strings from the cartridge (626 windows of 32 bytes),
all from source committed in this repository, as the host releases of this project do. The owner allowed
that on 2026-11-20 (D-12). The disk check (A-LEGAL) passes: no other byte of the ROM is on the disk.
