# Test sheet: NHL94AGA 0.7.0 (speed, the Genesis's own pace, the host menu)

About 30 minutes of play, then the checks if you have time. Run it on a **real A1200** with Fast RAM
(the baseline, D-14) if you have it, and once with no Fast RAM if you can. Have your ROM disks
(`nhl94-rom-a.adf`, `nhl94-rom-b.adf`) or `NHL94ROM:nhl94.bin` ready, as before.

## Play

1. Boot `nhl94-aga-v0.7.0.adf`. It loads your ROM (swap disks when asked), then shows the **host menu**.
2. In the menu: cursor keys or the joystick to choose and change, Return / fire / Start to go, Esc to quit.
   Try each setting once (60 Hz and 50 Hz on separate boots). Choose **Start the game**.
3. The EA and High Score screens, then the title. Press **P** (or Play on a CD32 pad) for Start.
4. Play a match with the joystick in port 2 (fire 1 = B, fire 2 = A, C on Space/Return, Start on P),
   or a CD32 pad, or the keyboard (cursor keys, Z X C, P).
5. Press **Esc** to quit. The Shell comes back; `NHL94VFY.log` says what happened, including the line
   `pacing: the vblank ... Hz, the Genesis ... Hz, ... ppm`.

Write down:

| Item | Result (fine / wrong: what you saw or heard) |
|---|---|
| The host menu: readable, every setting changes, the choices still there on the next boot | |
| The 50 Hz choice: the game runs (slightly slower, as the PAL cartridge) and the picture is centred | |
| The match picture: rink, players, puck, clock and score, the boards in front of the players | |
| Match speed: the game's clock against a stopwatch (a 5-minute period should take the same time as on a Genesis) | |
| Smoothness: how often the picture seems to skip a frame in a match, on the title, on the roster screen | |
| Sound: music, the crowd, the organ, effects; anything missing or out of tune | |
| Controllers: joystick, CD32 pad, keyboard, the swapped ports, Esc | |
| A record or a playoff saved, still there after quitting and booting again | |
| The `pacing:` line from `NHL94VFY.log` (the real A1200's screen rate) | |

## The checks (optional)

* The private show disk: `NHL94VFY name_entry SHOW` ends with `A-DISPLAY-PLANES: PASS`.
* The private show disk, timing: `NHL94VFY pause_menus SHOW TIME SKIP` (its last lines: passes not drawn).
* The private audio disk: `NHL94VFY name_entry AUDIO` ends with `A-AUDIO-CMD: PASS`.
* The verify disk, as before: `A-LOGIC: PASS`.

Send back `NHL94VFY.log` from each run and the table.
