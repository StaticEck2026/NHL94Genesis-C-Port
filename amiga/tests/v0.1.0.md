# Test sheet: NHL94AGA 0.1.0 (phase P1, toolchain and boot)

One sitting, about 15 minutes. Run it on a **real A1200**. An emulator or an FPGA core does not count
(PROMPT.md rule 2). Write the results into the table at the end and send it back with the log file and a
photo of the screen.

## What you need

* The A1200, as stock as you have it. Write down every expansion (accelerator, Fast RAM, IDE drive,
  PCMCIA card): the gates are judged on a stock machine.
* Kickstart 3.0 and, if you can swap chips, 3.1. Each is a separate run.
* A floppy with `nhl94-aga-v0.1.0.adf` on it. Write down how you made it (a real disk written with
  ADF-Copy, Greaseweazle or an Amiga-side tool, or a Gotek). A Gotek only stands in for the drive, so it
  is fine for this test. Write down which you used.
* For step 5, your own Workbench (on a hard disk or a floppy), to run the program from the Shell.
* A monitor or TV on the RGB port.

## Steps

1. **Boot the disk** with no other disk in any drive. A Shell window shows
   `NHL94AGA (native Amiga 1200 AGA port), see ReadMe ...`, and the screen goes black.
2. **Look at the test screen.** You should see:
   * three white lines: `NHL94AGA 0.1.0 (P1 boot test)`, `Kickstart 40.068 AGA PAL` (your version and
     your PAL or NTSC), `Chip RAM free: ... KB`, and `Left mouse or fire: back to the OS`;
   * below them, a band 64 lines tall going smoothly from blue to pink. On AGA each line is its own
     colour, with no visible steps. If you see about 16 wide stripes, write it down: the 24-bit palette
     is not working;
   * below the band, a short yellow bar moving up and down smoothly, once a frame, with no flicker or
     tearing.
3. **Hold for about 20 seconds**, timed with a watch. Then press the **left mouse button** (or fire on a
   joystick in port 2). The Shell comes back and prints the log:
   ```
   NHL94AGA 0.1.0 (DD.MM.YYYY) <commit>
   Kickstart 40.068, CPU 68020, chipset bits $.., PAL
   Took the machine and gave it back: N vblanks, N copper frames
   Chip free before ..., after ...; all free before ..., after ...; other before ..., after ...
   A-FIRMWARE memory check: PASS
   Log written to PROGDIR:NHL94AGA.log
   ```
   N should be about 50 a second on PAL, or 60 on NTSC (about 1000 or 1200 for 20 seconds).
4. **Check the machine is fine afterwards**: type `dir` and press Return. The disk lists, and the drive
   light goes off afterwards.
5. **Boot your own Workbench**, put the NHL94AGA disk in DF0: (or DF1:), open a Shell, and run:
   ```
   Version DF0:NHL94AGA
   DF0:NHL94AGA
   ```
   `Version` prints `NHL94AGA 0.1.0 (DD.MM.YYYY)`. The test screen appears as in step 2. Press the left
   mouse button. **Workbench must come back as it was**: windows redrawn, mouse pointer working,
   drives working (open a drawer).
6. If you can, **repeat steps 1 to 5 on the other Kickstart** (3.0 and 3.1).
7. Optional: **start it from a 68000 machine or an ECS one** (A500, A600). It must refuse with a
   message ("needs a 68020" or "needs the AGA chipset") and not crash.
