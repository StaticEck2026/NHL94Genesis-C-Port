# Test sheet: NHL94AGA 0.6.0 (the game on screen, with sound and controllers)

About 30 minutes of play, then the checks if you have time. Run it on a **real A1200** with Fast RAM
(the baseline, D-14) if you have it. Have your ROM disks (`nhl94-rom-a.adf`, `nhl94-rom-b.adf`) or
`NHL94ROM:nhl94.bin` ready, as for 0.5.x.

## Play

1. Boot `nhl94-aga-v0.6.0.adf`. It loads your ROM (swap disks when asked), then the screen changes to
   the game.
2. The EA and High Score screens, then the title. Press **P** (or Play on a CD32 pad) for Start.
3. Play a match with the joystick in port 2 (fire 1 = B, fire 2 = A, C on Space/Return, Start on P),
   or a CD32 pad, or the keyboard (cursor keys, Z X C, P).
4. Press **Esc** to quit. The Shell comes back; `NHL94VFY.log` says what happened.

Write down:

| Item | Result (fine / wrong: what you saw or heard) |
|---|---|
| The title and menus look like the Genesis's (colours, positions) | |
| The match picture: rink, players, puck, the clock and score, the boards in front of the players | |
| Scrolling: smooth, no tearing or wrong strips at the edges | |
| Speed: the menus at full speed; the match (expected slow in this version: about half speed) | |
| Sound: music, the crowd, the organ, effects; anything missing or out of tune | |
| Controllers: joystick, CD32 pad, keyboard, Esc | |
| A record or a playoff saved, still there after quitting and booting again | |

## The checks (optional)

* The private show disk: `NHL94VFY name_entry SHOW` ends with `A-DISPLAY-PLANES: PASS`.
* The private audio disk: `NHL94VFY name_entry AUDIO` ends with `A-AUDIO-CMD: PASS`.
* The verify disk, as in 0.5.x: `A-LOGIC: PASS`.

Send back `NHL94VFY.log` from each run and the table.
